# 🛒 স্মার্ট বাজারের হিসাব (Smart Shopping List) - PWA

**স্মার্ট বাজারের হিসাব** একটি আধুনিক, মোবাইল-ফ্রেন্ডলি এবং অফলাইন-সাপোর্টেড প্রোগ্রেসিভ ওয়েব অ্যাপ (PWA)। বাজারে গিয়ে একসাথে অনেক পণ্য কেনার সময় কোনটির দাম কত হলো এবং মোট কত খরচ হলো, তা তাৎক্ষণিকভাবে ট্র্যাক করার জন্য এটি একটি চমৎকার টুল। 

---

## ✨ প্রধান ফিচারসমূহ (Features)

- **📝 মাল্টি-লিস্ট ম্যানেজমেন্ট:** একসাথে একাধিক লিস্ট (যেমন: মুদির বাজার, কোরবানির বাজার) তৈরি এবং সংরক্ষণ করার সুবিধা।
- **✅ রিয়েল-টাইম চেকলিস্ট:** কেনাকাটার সময় আইটেমগুলো টিক (Checkbox) দিয়ে মার্ক করার সুবিধা।
- **✏️ ইনস্ট্যান্ট আপডেট:** বাজারে গিয়ে যেকোনো সময় পণ্যের পরিমাণ, দর বা ছাড়ের হিসাব পরিবর্তন বা আপডেট করার সুযোগ।
- **📦 স্পষ্ট ইউনিট ও নোটস:** পণ্যের সাথে কেজি, পিস, লিটার ইত্যাদি একক (Unit) এবং অতিরিক্ত তথ্যের জন্য নোট/মন্তব্য (Remarks) যোগ করার সুবিধা।
- **📅 কাস্টম তারিখ:** স্বয়ংক্রিয়ভাবে বাংলা বার সহ সঠিক ফরম্যাটে (`DD-MM-YYYY`) তারিখ প্রদর্শনের ব্যবস্থা।
- **💾 অটো-সেভ (Local Storage):** কোনো ডাটাবেজ ছাড়াই ব্রাউজারের মেমোরিতে ডাটা সম্পূর্ণ সুরক্ষিত থাকে। অ্যাপ বা ব্রাউজার বন্ধ করলেও লিস্ট হারাবে না।
- **📸 ইমেজ শেয়ারিং:** এক ক্লিকে পুরো শপিং লিস্টটিকে একটি সুন্দর ছবিতে রূপান্তর করে WhatsApp, Telegram বা Messenger-এ শেয়ার করার সুবিধা।
- **📱 PWA ও অফলাইন সাপোর্ট:** এটি ইন্টারনেট ছাড়াই অফলাইনে কাজ করে এবং মোবাইলের হোম স্ক্রিনে নেটিভ অ্যাপের মতো ইনস্টল করা যায়।

## 🚀 কীভাবে ব্যবহার করবেন? (How to Run)

এই প্রজেক্টটিতে কোনো ব্যাকএন্ড বা জটিল সেটআপের প্রয়োজন নেই। 

### ১. লোকাল কম্পিউটারে চালাতে:
1. এই রিপোজিটরিটির কোড ডাউনলোড (ZIP) বা ক্লোন করুন।
2. ফোল্ডারের ভেতর থাকা `index.html` ফাইলটি যেকোনো ব্রাউজারে (Chrome, Firefox, Edge) ডাবল-ক্লিক করে ওপেন করুন।

### ২. মোবাইলে অ্যাপ হিসেবে ইনস্টল করতে (PWA):
1. প্রজেক্টটি যেকোনো ফ্রি হোস্টিং সার্ভিসে (যেমন: GitHub Pages, Vercel, Netlify বা Cloudflare Workers) হোস্ট করুন।
2. আপনার মোবাইলের ব্রাউজার (যেমন Google Chrome) থেকে ওই লিংকটি ওপেন করুন।
3. ব্রাউজারের মেনু থেকে **"Add to Home Screen"** বা **"Install App"** অপশনে ক্লিক করুন।
4. এখন এটি আপনার মোবাইলের স্ক্রিনে একটি সাধারণ অ্যাপের মতো আইকন সহ যুক্ত হয়ে যাবে।

## 🛠️ ব্যবহৃত প্রযুক্তি (Tech Stack)

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Storage:** Browser Local Storage API
- **Libraries:** `html2canvas` (লিস্ট ইমেজ আকারে রেন্ডার করার জন্য)
- **PWA Capabilities:** Web App Manifest (`manifest.json`), Service Worker (`sw.js`)
